# Earth Engine Remote Sensing

Introductory Google Earth Engine JavaScript practice. The current scripts demonstrate filtering a Sentinel-2 image collection by cloud percentage, date and geometry.

Open the files in the [Earth Engine Code Editor](https://code.earthengine.google.com/) and replace the example point or date range as needed. Future NDVI, NDWI, cloud-masking, classification and accuracy-assessment scripts can be added directly at repository root as they are recovered.

These files are deliberately described as foundational exercises; the repository does not claim advanced analysis that is not present in the source.
